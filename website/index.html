采集工作流

机器负责整理，
你决定值得留下什么。

不是一份固定图单，而是一套可以在自己的目录里重复运行的采集与复现流程。

1
提供论文

给一个论文名，或一条链接

Skill 查找准确来源、读取完整论文，并清点所有编号图和表。方法框架、实验结果和表格，各归其位。

2
提取与初筛

精选好图，保留来路

从正文和附录中筛选方法图、定量图表与特色表格，排除普通表格和定性截图。完整保留图中标签与图例，记录来源和取舍原因。

3
人工筛选

停下来，等你挑选

收到真实的本地目录后，你可以删除、替换、重命名或新增图片。没有确认，就不会继续生成条目。

“检查好了，用目录里的图片继续。”
4
重建可编辑资源

留下原图，也留下重建配方

方法图提供对应的可编辑 PPTX，每张图一个下载入口。实验图提供 Python，表格提供 LaTeX。估读数据、简化结构和未完成的重建都会说明。

5
更新图库

README 与网页，一起更新

使用你确认后的当前图片，生成论文 README、更新主索引，再构建网页。收藏、品牌和研究方向，由你掌控。

由你确认

自动化流程，
不自动替你决定。

AI 先按视觉与复用价值初筛，人做最后的选择。重建不是原作者源码恢复，也不等同于原始实验数据。

materials / YourPaper /
├─ method_figures/
├─ result_figures/
└─ tables/

搭建指南

把这套工作流，
带进你的研究。

Fork 项目，安装 Skill，从你关心的第一篇论文开始。网页负责浏览和下载，采集与筛选在本机完成。

1 · 创建仓库

拥有自己的仓库

Fork 项目保存自己的选集，或 clone 到本机。现有素材的许可不自动转移，发布前请核对原作者的再分发要求。

在 GitHub Fork ↗
git clone https://github.com/lyc61c/PaperFigureAssets.git ReFigure
2 · 安装 Skill

安装图表采集 Skill

将下面的指令发给 Codex 安装完整 Skill。调用名为 $paper-asset-builder，PPT 复现流程已内置。

$skill-installer 请从 https://github.com/lyc61c/PaperFigureAssets 的 paper-asset-builder 目录安装 skill。
Codex / Claude Code 安装指南 ↗
3 · 收录论文

写下想收藏的论文

复制给本地 AI 助手，拿到目录后检查，再回复确认。网页不会提交输入内容。
4 · 配置图库

让它成为你的图库

品牌、描述与精选论文在一个配置文件里。网页从独立的 PAPER_INDEX.md 索引构建，未收录的临时目录不会自动公开。

python website/build.py python -m http.server 8000 --directory website/dist
